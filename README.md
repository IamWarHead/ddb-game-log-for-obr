# DDB Gamelog for Owlbear Rodeo

Bring your D&D Beyond rolls to [Owlbear Rodeo](https://www.owlbear.rodeo/). The GM sets it up once; **players install nothing.**

Rolls made on dndbeyond.com or in the D&D Beyond player app show up in a roll list and as cards on the map, for everyone in the room. The extension uses the same Gamelog server and the same Patreon membership as the [Foundry VTT module](https://iamwarhead.github.io/ddb-game-log/).

**Documentation:** https://iamwarhead.github.io/ddb-game-log-for-obr/

## Install

In Owlbear Rodeo, add the extension with this manifest URL, then switch it on in your room:

```text
https://obr.datapoint.hu/manifest.json
```

Step by step: [Install](https://iamwarhead.github.io/ddb-game-log-for-obr/install.html), then [First steps](https://iamwarhead.github.io/ddb-game-log-for-obr/first-steps.html).

## Features

- **Rolls in the room:** a roll list and cards on the map, with kept and dropped dice, pending "rolling…" cards and D&D Beyond roll privacy. Free.
- **Card look:** themes and character avatars (Basic).
- **Character linking:** link tokens to D&D Beyond characters by hand (free), or import the party (PRO).
- **Initiative:** an initiative roll sets the token's place in Owlbear Rodeo's Initiative Tracker, with an optional Dexterity tiebreaker. Free.
- **Live token stats (PRO):** hit points and armor class follow D&D Beyond through Stat Bubbles for D&D.
- **Monster rolls and the D&D Beyond player app (PRO).**
- **Avrae rolls (PRO, experimental).**
- **Statistics:** party overview, highlights, luck, awards, charts, session history, import, export and a session recap.
- **Discord (PRO):** public rolls and the session recap in your channel.
- **Other Owlbear extensions (experimental):** rolls from extensions that support it join the roll list.

Every feature page states the tier it needs, see [Features](https://iamwarhead.github.io/ddb-game-log-for-obr/features/) and [Tiers](https://iamwarhead.github.io/ddb-game-log-for-obr/tiers.html).
