# Card look

**Tier:** Basic.

You can change how roll cards look, in the roll list and on the map.

{% include screenshot.html src="card-themes.png" alt="Roll cards in two or more card themes side by side" %}

| What | Tier |
| --- | --- |
| Card themes | Basic |
| D&D Beyond character avatars on cards | Basic |

## Card themes

Pick a theme under **Settings → Rolls & cards → Card look → Roll card theme**. A theme colours the cards and gives each roll type its own accent colour, as on D&D Beyond's game log. It applies to everyone in the room, not only to you, and players do not need a membership to see it.

| Theme | |
| --- | --- |
| Default | The Gamelog look |
| D&D Beyond light | D&D Beyond's game log colours, light |
| D&D Beyond dark | D&D Beyond's game log colours, dark |
| Vampire's Crypt | dark |
| Frostfell | dark |
| Tavern | dark |
| Parchment | light |
| Fey Grove | light |

{% include screenshot.html src="card-theme-setting.png" alt="Settings, Rolls and cards page, Card look section with the theme list" %}

The same palettes are in the Foundry module, so a table that plays in both looks the same.

## Character avatars

With Basic, a card shows the character's D&D Beyond avatar next to the name. Without it, cards have no picture.

## Without Basic

Without a Basic membership the cards still work: they use the default look and show no avatar. The theme setting is locked and offers an upgrade to the GM. See [Tiers]({{ '/tiers.html' | relative_url }}).

{: .note }
The theme and the avatars follow the membership of the GM whose browser relays rolls. If another GM takes over, their membership decides, see [Only one GM relays]({{ '/troubleshooting.html' | relative_url }}#relaying-gm).
